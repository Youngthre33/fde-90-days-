## 4. 本课核心代码

```python
try:
    cursor = connection.execute(
        "SELECT id, title, status FROM tickets WHERE id = %s",
        (ticket_id,),
    )
    row = cursor.fetchone()
    print("查询结果：", row)
finally:
    connection.close()
```

### try:

开始连接建立后的查询与显示工作，最后由finally收尾。connect本身失败会在进入try前报错；try不是让错误消失。

### cursor = connection.execute(

通过当前connection发送查询，并取得管理本次查询结果的cursor。这里execute收到两项内容：SQL文字、查询要使用的值。cursor不是工单列表；后面的fetchone才取得一行。

### "SELECT id, title, status FROM tickets WHERE id = %s",

- SELECT id, title, status：要取出的三列是编号、标题、状态。
- FROM tickets：从tickets表查询。
- WHERE id = %s：只保留编号等于本次参数值的记录。
- WHERE在这里用来筛选行，SQL中的等号是相等条件，不是在给数据库id重新赋值。
- %s：Psycopg要求的值占位符，意思是此处的具体值由execute的下一项参数提供。查询整数也用%s，不改成%d，不写成带单引号的'%s'。
- 双引号：这一整段在Python中是字符串，里面的内容作为SQL交给数据库执行。
- 引号后面的逗号：分开execute的第一项参数与第二项参数。

今天只有一个占位符，对应提供一个编号，不额外引入多个条件。

### (ticket_id,),

这行提供查询实际使用的参数。当前ticket_id是3，所以(ticket_id,)相当于(3,)。

这是一个只装一个值的元组。execute使用这种按位置提供值的方式时，需要收到一组值；即使只有一个值，也按一组提供。

```python
(3)    # 仍然是整数3
(3,)   # 只有一个元素的元组
```

括号内的逗号是关键：它让Python知道这是单元素元组，而不是给数字加一对普通括号。括号内的逗号不能因为只有一个参数就删掉。括号外最后一个逗号是调用参数末尾的逗号，允许省略；两个逗号作用不同。

SQL文字和参数值作为两项内容交给psycopg，由它处理值与占位位置的对应，不手动用字符串拼接。以本例来说，查询效果就是筛选id等于3的工单；不把这个效果描述为Python直接把字符串里的%s替换成3。之后改ticket_id的值就能使用同一条查询查别的编号。

### )

结束execute调用。SQL文字与(ticket_id,)在这同一次调用里一起交给execute。

### row = cursor.fetchone()

fetchone取出本次结果的下一行，首次调用取得第一行；row接住它。id是主键，不能重复，因此这个WHERE条件最多匹配一行。是WHERE id筛选和id唯一性决定最多一行，不是fetchone替我们找出了指定编号。

查到时row是一行元组，例如(3, '某张工单的标题', 'open')；没匹配的行时row为None。本处不采用返回列表的fetchall，所以没找到时不是[]。None本身不表示连接失败或删除了数据。

### print("查询结果：", row)

在终端显示提示文字和取得的这一行。默认没有if分支，因此没找到就直接显示“查询结果： None”。print不会自动把结果交给网页。

### finally: 与 connection.close()

无论try中的查询或打印正常结束还是出现异常，都尝试关闭这一次连接，错误本身仍会报告。只做SELECT没有写入要commit；关闭不清空数据库。
