第一行导入连接PostgreSQL所用工具，第二行取得连接配置。与前几课相同，导入本身不建立连接。

```python
def get_connection():
    return psycopg.connect(
        host=settings.db_host,
```

- def定义函数。get_connection是函数名字，可理解为“取得一个连接”。定义时空括号表示不要求调用处传参数；所需配置在内部从settings读取。

- connect_timeout=5是建立连接的超时设置，不是连接只能用5秒。
- 最后一行右括号结束connect调用。

以前在每个函数里直接写connect参数；这里把重复连接代码放进get_connection，查询、新增等需要连接时都能调用。每次调用建立自己的连接，不把它理解成所有功能共用一条永不关闭的连接。

## 3. 第二段：整理一行结果

```python
def row_to_ticket(row):
    if row is None:
        return None

    return {
        "id": row[0],
        "title": row[1],
        "status": row[2],
    }
```

- row_to_ticket是我们自己起的函数名，表示“把取出的一行整理成工单字典”，不是Python关键字。row接收调用处交来的结果。
- if row is None检查是否没有查到行。条件为真时return None交回“没找到”，本次函数立即结束，不执行下面的row[0]。
- 查到行时，return后花括号创建并交回字典。
- "id": row[0]用第0项作为编号；"title": row[1]用第1项作为标题；"status": row[2]用第2项作为状态。键后冒号把名称和值配在一起；逗号分隔项目。

这段只整理已经拿到Python内存中的结果，不连接数据库、不执行SQL，也不更改数据库。与Day117整理字典是同一件事，现在单独起名，其他查询结果也能复用。

## 4. 第三段：按编号查询

```python
def find_ticket_by_id(ticket_id: int):
    with get_connection() as connection:
        cursor = connection.execute(
            "SELECT id, title, status FROM tickets WHERE id = %s",
            (ticket_id,),
        )
        row = cursor.fetchone()

    return row_to_ticket(row)
```

- find_ticket_by_id定义按编号查工单的函数。ticket_id接收传来的编号；: int是类型标注，说明这里期望整数，不会仅凭这一标注自动检查所有普通Python调用。
- get_connection()括号表示调用刚才第一个函数：它建立连接并return连接对象。with管理这个连接，as connection使本函数用connection操作它。成功退出时提交结束当前事务并关闭；这里只SELECT，没有新增/修改的业务数据要保存。
- connection.execute调用当前连接发送SQL，cursor接收返回的游标，之后通过它取结果。
- SQL选择三列，从tickets表中筛选id等于给定参数的一行；%s的位置由下一行提供。
- (ticket_id,)传一个参数。调用时编号1进ticket_id，这里就把1交给SQL。逗号表示单元素元组，不是生成第二个参数。
- 右括号结束execute调用。
- row = cursor.fetchone()取出一行，没匹配则是None。row保存取得的Python结果，不是数据库表本身。
- 最后一行缩进与with对齐，已在with之外，所以此时连接已经完成收尾。调用row_to_ticket(row)，将刚取得的结果交给整理函数；整理函数返回字典或None后，外面的return再将同一个结果交给find_ticket_by_id的调用者。

最后一行的顺序是：传入row → 整理函数执行 → 得到字典/None → 查询函数把它继续交回。两个函数各有自己的参数/局部名字，即使都写row，也是在传值后分别使用；不是“全项目自动共享一个变量”。

## 10. main的接收、查询和返回

```python
def get_ticket(
    request: Request,
    ticket_id: int = Path(ge=1),

```

def定义收到这类请求后执行的get_ticket函数。request由FastAPI提供，是当前HTTP请求对象，携带路径等信息。ticket_id由地址里的同名位置取得，int使FastAPI按整数解析/校验；Path说明从URL路径取值，ge=1要求编号至少为1，不表示默认编号等于1。路径输入不合法时可能在进入函数前被拒绝，不是先执行SQL。
