## 1. 今天要做什么，为什么要做

以后做工单系统，需要有一个地方长期保存工单，也需要有一个方便查看它的工具。今天先认识并找到这两个软件，完成安装或确认已有安装，最后打开管理工具。

| 今天遇到的名称 | 它的用途 |
| --- | --- |
| PostgreSQL | 数据库软件，负责保存、查询和管理数据。安装后的数据库服务在后台工作。 |
| pgAdmin 4 | 图形管理工具，供你通过窗口和按钮操作 PostgreSQL。 |

现在先记住各自职责：**PostgreSQL 管理数据，pgAdmin 4 提供操作界面。** PostgreSQL 官方提供的 Windows 安装器可以一起安装这两个软件。[官方 Windows 安装入口](https://www.postgresql.org/download/windows/)

今天的终点是“我知道各自用途，而且能打开 pgAdmin 4”。连接字段和端口留到 Day106，再逐项解释；建库、建表和 Python 后端接入按后续 Day 进行。

## 2. 先看电脑里是否已经有它们

1. 点击 Windows 的“开始”，在搜索框输入 `pgAdmin 4`。
2. 看搜索结果有没有这个应用。有的话，点击打开，稍等它显示主窗口。
3. 打开 Windows“设置”，找到“应用”里的已安装应用列表，搜索 `PostgreSQL`，记录显示的名称和版本。不同 Windows 版本的列表名称可能略有不同。

如果两者已有安装，而且 pgAdmin 4 能打开，本课继续使用它们，直接看第 5 节。**为了重新学习，不需要卸载或重装。** 如果只找到了其中一个，先记下实际结果，按缺少的部分处理。

这里的“打开”主要指打开 pgAdmin 4 的管理窗口；PostgreSQL 数据库服务在后台运行，不要求出现一个同名编辑窗口。

## 3. 缺少软件时，到哪里下载

### 3.1 尚未安装 PostgreSQL

打开 [PostgreSQL 官方 Windows 下载页](https://www.postgresql.org/download/windows/)，找到 **Download the installer**，点击进入 EDB 提供的安装器下载页。

- `Download`：下载，把安装文件保存到你的电脑。
- `installer`：安装程序，运行后才会把软件装好。
- `Windows x86-64`：供 64 位 Windows 使用的安装包。

选择页面提供且适用于本机的受支持正式版本，不选标着 Beta 的测试版。记录你实际选的版本即可，不要求为了跟讲义的数字一致而反复换版本。官方页面说明该安装器由 EDB 提供，并包含 PostgreSQL 和 pgAdmin。[下载来源说明](https://www.postgresql.org/download/windows/)

下载完成后，在浏览器的下载记录或 Windows 的“下载”文件夹里找到安装文件。文件下载完成，表示安装程序已经到电脑里，还需要运行它。

### 3.2 PostgreSQL 已装好，只缺 pgAdmin 4

只下载 [pgAdmin 4 官方 Windows 安装包](https://www.pgadmin.org/download/pgadmin-4-windows/)，运行它安装管理工具。已有 PostgreSQL 继续保留。官方页面列出不同 pgAdmin 版本支持的 Windows 范围，选择适用于本机的正式版。

## 4. 使用 PostgreSQL 图形安装器

这一节适用于第 3.1 节下载的安装器。若已有完整安装，跳过这一节。

双击下载的安装文件；Windows 询问是否允许安装时，核对是刚下载的安装器后允许。安装向导会逐页出现。`Next` 是下一步，`Back` 是上一步，`Finish` 是结束。

按顺序填写：

| 界面文字 | 本课怎么做 | 这个名字的意思 |
| --- | --- | --- |
| Welcome | 点 Next | 安装欢迎页 |
| Installation Directory | 保留默认路径，点 Next | 软件程序的存放位置 |
| Select Components | 按下面的小表选择 | 选择一起安装的组成部分 |
| Data Directory | 保留默认路径，点 Next | 数据库保存数据的位置 |
| Password / Retype Password | 设置密码，再输入相同密码确认 | 数据库管理账号使用的密码 |
| Port | 保留安装器默认值，点 Next | 先完成这一页，Day106再解释用途 |
| Locale | 保留 Default locale | 使用默认的区域设置 |
| Pre Installation Summary | 核对刚才选择的内容 | 安装前汇总 |
| Ready to Install | 点 Next，等待安装结束 | 开始安装 |
| Finish | 取消 Launch Stack Builder，点 Finish | 完成安装 |

组件选择只看这四项：

| 组件 | 本课选择 |
| --- | --- |
| PostgreSQL Server | 勾选，安装数据库服务 |
| pgAdmin 4 | 勾选，安装管理窗口 |
| Command Line Tools | 勾选，后续会使用的命令工具 |
| Stack Builder | 不勾选，本课不用的额外工具下载器 |

密码只保管在自己本机的安全位置，课程笔记中写“已保管”即可，不填写密码本身。安装流程和组件名称依据 [EDB 官方 Windows 安装说明](https://www.enterprisedb.com/docs/supported-open-source/postgresql/installing/windows/)。

如果安装出现报错，先记录哪一页以及报错文字，再处理这一处；不用为了跳过错误去反复卸载重装。

## 5. 打开 pgAdmin 4，确认看到什么

1. 点击 Windows“开始”，搜索 `pgAdmin 4`。
2. 点击应用，等到主窗口出现。
3. 找到左侧对象列表区域，看看是否有 `Servers` 这一项。

通常左侧有对象列表，右侧是主页或工作区域；版本和布局设置可能让位置略有不同。`Servers` 可以先理解为保存数据库连接项目的地方。现在先认位置，连接操作在 Day106 进行。[pgAdmin 官方入门界面说明](https://www.pgadmin.org/docs/pgadmin4/latest/getting_started.html)

**本课预期结果：** 能在电脑上确认 PostgreSQL 已安装，能亲手打开 pgAdmin 4，并找到它的主窗口。如果此时弹出密码或其他对话框，先记下对话框标题，以实际文字区分下一步；不把密码写进聊天或笔记。

## 6. 课后小测

本课实际采用以下两个核心理解题，学习者已于 2026-09-28 作答并通过讲评。不为凑满三题追加常识题。

1. 在 pgAdmin 中要求“查看所有工单”，真正查找数据的是谁，把结果显示给人看的又是谁？
   - 学习者回答：PostgreSQL 查找，结果给 pgAdmin 4。
   - 讲评：正确。完整说法是 PostgreSQL 查找并返回结果，pgAdmin 4 将结果显示给操作它的人。
2. 一张工单已经提交保存，关闭 pgAdmin 窗口会不会让它消失，为什么？
   - 学习者回答：不会，因为 PostgreSQL 已经真正提交。
   - 讲评：正确，能够区分已提交的数据和管理窗口；本题不评价尚未提交修改的处理。
