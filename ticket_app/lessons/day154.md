## 操作二：由用户替换messages这一小段

将函数内从messages = [到对应结束]的一整个赋值替换为以下代码，保留开头四个空格，使其仍在函数内部：

```python
    messages = [
        {
            "role": "system",
            "content": (
                "你是工单助手，输入资料是工单的标题和状态。\n"
                "任务：概括问题，给出可由工作人员执行的下一步建议。\n"
                "约束：摘要只写已知事实；未知原因写“待确认”，不要编造。\n"
                "不要声称已联系客户、解决问题或修改工单。\n"
                "输出：用中文，依次写【工单摘要】【建议下一步】【待补充信息】。\n"
                "摘要最多2句；建议最多3条；待补充信息最多3项。"
            ),
        },
        {"role": "user", "content": ticket_text},
    ]
```

- messages仍是两条消息组成的列表。
- 第一条system的content给模型工作说明。content后括号用于分行书写，相邻的字符串会合成一整段文字；此处不是调用函数。
- 每个\n在运行时变为换行，让各项说明分开。
- 第二条user仍从参数ticket_text取得本次工单资料，没有把某张工单硬写进固定规则。
- 这些文字由Python装进请求，模型平台据此生成回答；不是Python执行“联系客户”“修改工单”等动作。
